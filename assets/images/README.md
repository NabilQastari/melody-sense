# Logo Assets per Tema untuk Melody Sense

Silakan letakkan file gambar logo PNG Anda di dalam folder `assets/images/` ini dengan nama-nama berikut untuk menyesuaikan 5 tema yang ada di Melody Sense:

| Nama Tema | ID Tema | Rekomendasi Nama File PNG | Keterangan Warna Tema |
| :--- | :--- | :--- | :--- |
| **Lavender Dream** (Default) | `default` | `logo_lavender.png` | Ungu Soft / Lavender (`#51508B` & `#8197E5`) |
| **Whisker Dark** | `whisker_dark` | `logo_whisker_dark.png` | Dark Charcoal & Whisker Red (`#FF2B4A` & `#FFF8EE`) |
| **Ocean Blue** | `ocean_blue` | `logo_ocean_blue.png` | Biru Samudra (`#1B3A5C` & `#4CA6D8`) |
| **Forest Green** | `forest_green` | `logo_forest_green.png` | Hijau Hutan / Fresh Green (`#2D5016` & `#6BBF4E`) |
| **Sunset Orange** | `sunset_orange` | `logo_sunset_orange.png` | Jingga Sunset / Warm Orange (`#6B2D10` & `#E88540`) |

### Spesifikasi Rekomendasi Gambar:
- **Format**: PNG dengan latar belakang transparan (atau bulat/persegi presisi).
- **Rasio**: 1:1 (Bujursangkar, misal 256x256 pixel atau 512x512 pixel).
- **Keterangan Fallback**: Jika salah satu file logo belum ditambahkan, aplikasi akan secara otomatis menampilkan icon cadangan tanpa error atau crash.
